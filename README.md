# DAREE.1 — GitHub Pages

## التشغيل
- ارفع `index.html` و`.nojekyll` إلى مستودع GitHub.
- من Settings → Pages اختر Deploy from a branch → `main` → `/(root)`.

## أكواد التفعيل
كل كورس له كود مستقل داخل النظام، والكود يفتح الكورس المرتبط به فقط.

> مهم: التفعيل الحالي يتم داخل المتصفح باستخدام localStorage، لذلك الأكواد ليست حماية سرية حقيقية. للحماية التجارية الفعلية يلزم Backend للتحقق من الدفع والأكواد.
